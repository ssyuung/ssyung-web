# 생성 이미지 작업 지시서

서비스 스크린샷이 아닌 이미지는 자식 에이전트가 만든다. 각 에이전트는 이 문서와 [README.md](../README.md)의 디자인 규칙을 먼저 읽는다.

## 공통 규칙

- 결과물은 `images/` 아래 지정한 파일 이름으로 둔다. `index.html`은 고치지 않는다. 연결은 메인 작업자가 한다.
- 브랜드 색만 쓴다. Green `#286B50`, Brown `#49372F`, Light Green `#A8D5B8`, Ivory `#FAF9F6`, Secondary `#F2EFE9`, Warm Gray `#F0EEE8`, Text `#302F2C`.
- 글꼴은 Pretendard. 손글씨·형광펜·테이프·장식 아이콘·그라데이션 장식 금지.
- 마디 로고와 서비스 화면은 지어내지 않는다. 공식 로고가 없으면 "마디 MADI" 글자 워드마크로 대신하고 그렇다고 보고한다.
- 사람이 나오는 이미지는 얼굴을 알아볼 수 없게(뒷모습, 손, 먼 거리). 실제 학교·학생으로 보이는 표식(교명, 명찰, 교복 로고)을 넣지 않는다.
- 만든 뒤 실제 크기로 열어 확인하고, 파일 경로·크기·만든 방법을 보고한다.

## 1. 링크 공유 이미지

- 파일: `images/og.png`, 1200×630
- 내용: Ivory 바탕. 왼쪽에 "마디마다, 함께."(그중 "마디"만 Green), 아래 "필요한 지원이 필요한 순간에 닿도록". 오른쪽에 `images/s1-problem.webp` 일부를 둥근 모서리 카드로.
- 카카오톡 미리보기에서 작게 보여도 제목이 읽혀야 한다. 가장자리 60px 안에는 글자를 두지 않는다.
- 만드는 방법 예: HTML로 그린 뒤 Playwright로 1200×630 캡처.

## 2. 파비콘·앱 아이콘

- 파일: `images/favicon.svg`, `images/favicon-32.png`, `images/apple-touch-icon.png`(180), `images/icon-512.png`
- 공식 심벌마크가 있으면 그것으로. 없으면 Green 바탕 원형에 Ivory "마" 한 글자로 임시 제작하고 임시라고 보고한다.

## 3. 02 문제 영역 사진

- 파일: `images/s2-photo.webp`, 가로 2400×914(21:8) 이상
- 장면: 체육관 입구 앞 복도에서 혼자 지원인력을 기다리는 초등학생의 뒷모습. 오전의 부드러운 자연광, 차분하고 따뜻한 색감. 아이보리·웜그레이 톤과 어울리게.
- 주인공은 가운데 1/3 안에 둔다. 휴대폰에서는 4:3으로 가운데만 보인다.
- 불안하거나 슬퍼 보이지 않게. "누가 데려가기로 했지?" 하는 잠깐의 기다림 정도.

## 4. 현장 사진 (선택)

- 파일: `images/field-teacher.webp`, `images/field-staff.webp`, 각 1600×1200(4:3)
- 장면: 특수교사가 태블릿으로 시간표를 확인하는 손과 책상 / 지원인력이 복도에서 학생과 나란히 걷는 뒷모습.
- 얼굴이 보이지 않게. 화면 속 내용은 흐리게 처리한다(가짜 UI를 또렷하게 그리지 않는다).

## 메인 작업자에게 돌려줄 것

파일 경로, 크기, 만든 방법, 임시로 대신한 부분(예: 로고 없음)을 짧게 정리해 보고한다.
